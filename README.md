# Basic Calculator Practice

## Overview

This project is a simple calculator application designed for practicing basic programming concepts. It allows users to perform common arithmetic operations and serves as an educational tool for learning and refining coding skills.

---

## Features

- **Basic Operations:** Addition, subtraction, multiplication, and division.
- **Input Validation:** Ensures user inputs are valid numbers.
- **Error Handling:** Handles common issues such as division by zero.
- **Modular Code:** Designed with reusable functions for each operation.
- **Expandable Design:** Easily add more operations or features in the future.

## Installation

Follow these steps to set up and run the calculator:

### Prerequisites
- Python 3.8 or higher

### Steps

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/KaedoW/Basic-Calculator-practice.git
   cd Basic-Calculator-practice
   ```

2. **Run the Calculator:**
   ```bash
   python calculator.py
   ```

---

## Usage

The calculator runs in the command-line interface (CLI). Users will be prompted to:
1. Enter two numbers.
2. Choose an operation from the following:
   - Addition (`+`)
   - Subtraction (`-`)
   - Multiplication (`*`)
   - Division (`/`)
3. View the result or an error message if the input is invalid.

---

## Examples

### Example 1: Addition
```plaintext
Enter the first number: 10
Enter the second number: 5
Choose an operation (+, -, *, /): +
Result: 10 + 5 = 15
```

### Example 2: Division by Zero
```plaintext
Enter the first number: 10
Enter the second number: 0
Choose an operation (+, -, *, /): /
Error: Division by zero is not allowed.
```
